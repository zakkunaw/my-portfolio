# 🎯 Quick Start Guide

Get your portfolio running in **5 minutes**!

## Step 1: Open Admin Panel (30 seconds)

Double-click `admin-panel.html` to open it in your browser.

## Step 2: Update Profile (2 minutes)

Click the **Profile** tab and fill in:

- **Full Name**: Your name
- **Job Title**: Your role (e.g., "Product Designer")
- **Bio**: Short description about you
- **Email**: Your contact email
- **Avatar URL**: Link to your profile picture
- **Available for Work**: Toggle if you're open to opportunities

Click **Save Profile**.

## Step 3: Add Projects (1 minute)

Click the **Projects** tab:

1. Click **Add Project**
2. Fill in:
   - Name: Project name
   - Description: Brief description
   - Color: Pick a color (#hex format)
   - Link: URL or `#` for no link
3. Click **Save**
4. Repeat for more projects

## Step 4: Add Products (1 minute)

Click the **Products** tab:

1. Click **Add Product**
2. Fill in:
   - Name: Product name
   - Tag: Category (e.g., "WEB TEMPLATE")
   - Color: Pick a color
   - Link: Product URL
3. Click **Save**
4. Repeat for more products

## Step 5: Preview Your Portfolio (30 seconds)

1. Open `index.html` in your browser
2. Check your profile appears
3. Navigate to Projects and Products pages
4. Everything should show your data!

## 🆘 Need Help?

**Admin panel not saving?**

- Make sure you clicked "Save Profile" button
- Check browser console (F12) for errors

**Data not showing on pages?**

- Refresh the page (Ctrl+R)
- Open in incognito mode
- Check localStorage in browser DevTools

**Want to start over?**

- Admin panel → Data tab → Reset to Defaults
