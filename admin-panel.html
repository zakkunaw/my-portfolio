GitHub Pages Setup

Steps to deploy to GitHub Pages:

  1. Export your data and save as data.json
  2. Create a GitHub repository
  3. Upload all HTML files + data.json
  4. Enable GitHub Pages in Settings
  5. Visit: username.github.io/repo-name

⚠️ Important Notes

  • Google Drive API memerlukan OAuth consent screen
  • Files akan disimpan di folder "Portfolio Media" di Drive kamu
  • Pastikan API Key dan Client ID sudah di-setup dengan benar
  • IndexedDB tetap sebagai fallback jika Google Drive tidak dikonfigurasi
